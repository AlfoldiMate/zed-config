2. Binding explorer

Every binding from the three sources, independent of focus. Group by first keystroke to see chords and prefixes, by action to see aliases, by context to see what each view carries.

3. Rule editor

Rules select from the defaults instead of starting from zero. They run in order: take copies matching bindings from a source, drop removes matching bindings from what has been taken so far, bind and unbind add or blank a key in a context. Patterns are regular expressions matched against the whole string. The result is a keymap.json you can copy, plus a report of chord prefixes, duplicates and unknown action names.
